# Origen — Landing page de café de especialidad

Página de aterrizaje estática para **Origen**, un tostador ficticio de café de altura. El proyecto aplica fundamentos de HTML semántico y CSS externo: jerarquía de encabezados, secciones, modelo de caja, selectores y estados interactivos. No utiliza JavaScript.

## Estructura del repositorio

```
/
├── index.html
├── styles.css
├── assets/
│   ├── cafe-origen.jpg
│   ├── finca-altura.jpg
│   └── marca.svg
└── README.md
```

## Cómo ejecutarla

1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` con un navegador (doble clic o arrastrándolo a Chrome, Firefox, Edge o Safari).
3. Opcional: si usas Visual Studio Code, puedes abrir la carpeta del proyecto y servirla con la extensión Live Server.

No hay dependencias ni proceso de compilación. Los estilos viven en `styles.css` y se cargan desde el `<head>` del HTML.
